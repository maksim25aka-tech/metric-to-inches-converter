# 📏 Metric to Inches Converter – 7 языков

Консольная утилита для перевода сантиметров (cm) или метров (m) в дюймы (inches). Реализована на 7 языках программирования.

## Формулы

- `1 in = 2.54 cm`  →  `inches = cm / 2.54`
- `1 in = 0.0254 m` →  `inches = m * 39.3700787`
